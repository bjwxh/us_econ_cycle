# 美国非农、通胀、利率与政治格局：可复现实证研究（第一版）

## 运行
在可联网的 Python 环境中：

```bash
pip install pandas numpy matplotlib scikit-learn yfinance
python research.py
```

程序直接从 FRED 获取：PAYEMS（季调非农总就业）、UNRATE、CPIAUCSL、FEDFUNDS、DCOILWTICO，以及 yfinance 的 ^GSPC（标普500价格指数，不含股息）。生成 `outputs/top5_macro_windows.csv`、`outputs/top5_cumulative_payroll.png`、`outputs/oos_forecasts.csv`、`outputs/oos_scores.csv`，以及 `top5_sensitivity_drop_month.csv`、`analog_sp500_forward.csv`、`oos_bootstrap.csv`、`live_forecast.csv`。

## 第二版更新（当前方法）
- **研究目标**：不是检验哪个党更利于就业，而是检验在就业增长相似时，政治格局与货币政策能否帮助预测后续市场走势。**预测目标改为标普500价格指数未来12个月涨跌**：从 t+1 月末到 t+13 月末，使t月全部数据发布后才建仓。训练样本只含标签在测试日前已知的行（滞后13个月）。
- **缺失数据不填充、不插值**：2025-10 缺失失业率与CPI（政府停摆未采集/未发布），2026-10 缺CPI（尚未发布）。匹配距离只在双方都有数据的格点上计算，并对当月剩余变量权重重新归一化（主结果）；敏感性检验为整月剔除（权重保持40/20/20/20），结果写入 `top5_sensitivity_drop_month.csv`。回测中含缺失特征的行直接丢弃。
- **回测基准与推断**：以历史均值预测为基准，报告 OOS R²；用移动区块自助法（块长13）给出平方误差改善的90%区间；另给出剔除2020年的结果。Ridge α=100为固定值，未调参。
- 实时预测取最近一个输入完整的月份（2026-09）。
- 局限：标普为价格指数；前五窗口仅5个样本，只能作案例参考；`oil_yoy` 自1987年起才有数据，使回测训练样本从约1987年开始。

## 研究问题与方法（第一版，部分已被上文替代）
1. **历史匹配**：将 2025/02–2026/10 共 21 个月的月度非农增长率、失业率水平、CPI 同比及联邦基金利率与历史 21 个月窗口做标准差归一化逐月距离比较。事前权重分别 40%、20%、20%、20%。仅使用 1960 年以来有完整数据的候选窗口。选出的前五个窗口互不重叠，避免相邻窗口挤占排名。历史累计就业图使用以窗口首月之前一个月为基数的累计增长百分比。
2. **预测研究**：使用宏观指标预测未来12个月非农总就业增长；与加入总统、众院、参院党派和分裂政府变量后的模型比较。Ridge 回归可解释为正态先验下的后验众数；这是一个**BVAR思想的简化基准**，不是严格的多方程 BVAR。两组模型都只用到测试日以前至少12个月的完整标签；样本外评分在2010–2024年，采用逐月扩展训练窗。
3. **统计推断限制**：月度预测误差因12个月重叠窗口而存在序列相关。MAE、RMSE差异只是探索性指标；正式推断还需区块自助法或HAC标准误，以及超参数调优的内层时间序列验证。
4. **政治变量限制**：逐月按月底时点赋值。党派映射采用众参两院多数党 / 组织控制权。对2001年6月Jeffords变更、2021年1月控制权交接作特殊处理；其余特别选举、空缺、短暂党派变化尚需官方逐日核对。2026中期选举结果不在2026年11月前的国会实际控制权中反映，2027年的结果在未来数据完成之前不应事先填入。
5. **因果与实时数据限制**：这是一项描述性相似度加预测力检验，不是政治党派对就业的因果识别；FRED最新修订数据不是当年初值，存在实时版本偏差；CPI滞后公布、月度政策利率平均、油价亦可能存在实时可得性问题；正式的投资前瞻回测需要按公布日期使用ALFRED vintages重跑。
